# CyberChefCloud

A personal project which is a fork of the CyberChef tool. I want to experiment allowing Cloud APIs as Ingredients (give it the power of AI)

## Ontology / RDF operations

Convert ontologies between Turtle, RDF/XML, JSON-LD, N-Triples, N-Quads, TriG and N3, run SPARQL queries, summarise an ontology's classes, properties and hierarchy, and draw it as an interactive graph, all in the browser. See [docs/OntologyOperations.md](docs/OntologyOperations.md).
